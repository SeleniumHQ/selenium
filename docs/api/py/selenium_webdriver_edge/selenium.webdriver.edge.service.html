Bases: ChromiumService

Service class responsible for starting and stopping msedgedriver.

Parameters:

  • executable_path (str | None) – Install path of the msedgedriver executable, defaults to msedgedriver.

  • port (int) – Port for the service to run on, defaults to 0 where the operating system will decide.

  • log_output (int | str | IO[Any] | None) – (Optional) int representation of STDOUT/DEVNULL, any IO instance or String path to file.

  • service_args (Sequence[str] | None) – (Optional) Sequence of args to be passed to the subprocess when launching the executable.

  • env (Mapping[str, str] | None) – (Optional) Mapping of environment variables for the new process, defaults to os.environ.

  • driver_path_env_key (str | None) – (Optional) Environment variable to use to get the path to the driver executable.
