selenium.webdriver.remote.script#

The supported script API, returned by driver.script.

Pinned scripts, script execution and console, JavaScript-error and DOM-mutation handlers. Nothing here hands back a protocol type: results are plain Python values and elements come back as WebElement, as with execute_script. See SeleniumHQ/selenium

If there is only one argument, it must be a dictionary mapping Unicode ordinals (integers) or characters to Unicode ordinals, strings or None. Character keys will be then converted to ordinals. execute(function_declaration, *args, context_id=None)[source]#

Execute JavaScript in the current window and return its result.

Arguments and return values are converted as by execute_script: WebElement arguments are passed to the page as elements, and elements in the result come back as WebElement.

Parameters:

  • function_declaration (str | PinnedScript) – The function to run, e.g. "(a, b) => a + b", or a PinnedScript returned by pin().

  • *args (Any) – Arguments passed to the function. When function_declaration is a PinnedScript, the single argument is the code to run with the pinned source in scope, e.g. "return helper();".

  • context_id (str | None) – The window handle to run in. Defaults to the current window.

Returns:

The function’s return value. When function_declaration is a PinnedScript, a ScriptResult instead, which reports failures through ScriptResult.error rather than raising.

Raises:

JavascriptException – If the script throws.

Return type:

Any

Example

total = driver.script.execute(“(a, b) => a + b”, 1, 2)
