selenium.webdriver.remote.accessibility_snapshot#

Accessibility snapshots computed in the page (ADR 18205).

The tree is computed by the accessibility-snapshot atom of @selenium/atoms. In a BiDi session it runs in a sandbox realm so page scripts cannot interfere with it; in a WebDriver Classic session it runs through Execute Script and child frames are reached by switching into them and back. The atom’s wire entry hands the tree back as one JSON string beside the element and frame references, so this module holds only what is the binding’s: the public node type and its text form, the mapping of references to WebElement, and frame stitching.

The output is computed from the DOM following WAI-ARIA, html-aam and accname; it is not the browser’s own accessibility tree and can differ from it at the edges.

to_text()[source]#

Render the tree as text, one node per line.

The line grammar is - role "name" [state] [state=value]: value, children indented two spaces, text leaves written as - text: content. An empty name is left out, as is an absent or empty value; a True state is written bare, a False one left out, any other value spelled. A line break or backslash in a value is escaped so a node never spans two lines. The description and element references are not rendered.

Returns:

The text form, without a trailing newline.

str
